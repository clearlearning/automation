2 Event & Ticket Types

In NOVI: Navigate to Event → Settings Tab → Scroll down to Event API Info → Copy the UniqueID value.
Enter all ticket types needed for this event. Ensure the value in the Label field matches the value in the same column in the CSV Template. Once uploaded, the system will match the value in the template to the tickets listed here.
In NOVI: Navigate to Event → Tickets Tab → Appropriate Ticket → Scroll down to Advanced Section → Copy the API UniqueID value → Paste in TicketUniqueID GUID field.
Give each ticket type a short label and its TicketUniqueId GUID. You'll assign these per-row below.
Note: Novi does not automatically price a registration from the ticket — confirmed by testing. This tool fetches each ticket's real price from Novi as soon as you enter its GUID (see the price shown below each ticket row) and sends that amount explicitly, marked Unpaid so it shows as an open balance.

3 Upload Registrant List

Populate the CSV template and upload below. The only required column is the email address; however, if you do not provide the other information, it will not populate in NOVI.
Expected columns (header row required, case-insensitive): FirstName, LastName, Email, CompanyName (optional), Phone (optional), TicketType (optional — matches a label above)
